# 反向拼字表情工坊 (fxbqb-studio)

一句话 → 九宫格/多宫格表情，一键生成。
本地运行，无需联网，**由 AI 协助开发完成**。

> **本地安全运行**：`app.py` 以 `server_name="127.0.0.1"`、`share=False` 启动，仅本机访问，不暴露公网接口。

---

## ✨ 特性

* 自动/手动网格：`auto`、`2x2`、`3x3`、`4x4`、`5x5`
* 渐变/纯色背景、圆角卡片、描边/阴影、留白与间距可调
* 同时导出整图与拆分小图（自动打包为 zip）
* **本地网页端 + 命令行** 双模式，**不调用外部付费 API**
* 支持中文字体（本地路径），跨平台可用开源字体

```bash

```

## 🚀 本地网页端（推荐）

```bash
python app.py
```

* 浏览器会自动打开本地页面（仅 `127.0.0.1` 可访问）。
* 在左侧填写文本与参数，点击「生成」即可在右侧看到合成图，并可下载拆分小图 zip。

---

## 🖥️ 命令行用法（可选）

```bash
python cli.py --text "你好，今天也要元气满满！" --grid auto --out out/grid.png --split out/slices
```

常用参数（节选）：

* `--font "C:\Windows\Fonts\msyh.ttc"` 指定字体文件（仅本地使用，不要随仓库分发）
* `--grid 3x3` 手动网格；或 `--grid auto` 自动
* `--bg_type gradient|solid`、`--bg_color1 #4285F4`、`--bg_color2 #F4B400`
* `--cell_size 256`、`--margin 40`、`--gap 12`、`--padding 16`
* `--stroke_width 6`、`--shadow`/`--no-shadow`

## 🔤 字体与合规

* 程序**不会分发**任何商用字体文件；如需中文显示，请在界面或命令行**填写本地字体路径**（例如 Windows 的 `C:\Windows\Fonts\msyh.ttc`）。
* 若需跨平台打包或发放，可改用 **开源字体 Noto Sans SC（思源黑体）**（OFL 许可，允许再分发）。
* 建议在 `.gitignore` 中排除字体文件与输出产物。

## 🛠️ 常见问题（FAQ）

**Q1：中文不显示或是方块？**
A：请在网页端的“字体路径”输入框填入本地中文字体路径；或命令行加 `--font "路径\到\字体文件"`。

**Q2：输出太小/太大？**
A：调整 `--cell_size`（单元格大小）与 `--font_size`；同时可微调 `--margin`、`--gap`、`--padding`。

**Q3：我不想开网页，只要命令行？**
A：直接用 `cli.py` 即可；网页端与命令行互不依赖。

**Q4：是否联网、是否用到第三方 API？**
A：默认**不联网**、**不调用付费 API**；网页仅在本机 127.0.0.1 运行。
